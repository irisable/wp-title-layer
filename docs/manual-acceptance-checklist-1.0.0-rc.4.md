# rc.4 聚焦验收

- [ ] 同一系列的两篇全系列序文，只出现一个“系列序文”栏目；各自显示“序一／序二”。
- [ ] 全系列后记、附录同样合并；空栏目不出现，季内仍以季名显示。
- [ ] 区块编辑器先选角色，再选所属范围和季；非正文公开标签位于排序提示之前。
- [ ] 主要文章可编辑内容分组；改成序文后隐藏分组并提示旧值保留，前台不再显示分组。
- [ ] 切回主要文章，原分组恢复；经典编辑器操作结果一致。
- [ ] Publisher 升级后可选序文等角色，并区分全系列／单季，发布后 WordPress 读回一致。
- [ ] Publisher 连接旧 WPTL 时普通文章照常，高级角色写入明确受限，不静默降成主要文章。

后台结构、篇序和既有文章内容不迁移。两个插件都需要安装各自新构建才能完整联调。

## 已完成的本地验证

- 临时 WordPress 中文归档：桌面及 390px 手机，两篇序文只有一个栏目。
- 区块编辑器：角色先于范围，非正文隐藏分组，切回主要文章恢复旧值。
- 经典编辑器：条件字段隐藏正常；修改公开标签并保存后，旧分组仍保留。
- Publisher 六类真实请求夹具通过 WordPress REST 写入、读回与发布；额外检查常规保存不改变私有篇序，共 46 项。
- Publisher 本地 lint、类型检查、生产构建及 281 项测试通过；未做真实 Obsidian 窗口、NAS 或正式站端到端验收。
