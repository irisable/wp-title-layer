# WP Title Layer 1.0.0-rc.2 人工验收清单

本清单只验证 rc.2 的中文术语与高级结构前台表达。迁移、篇序、REST、SEO 和
模板数据契约没有变化。

## 1. 覆盖升级

- [ ] 从 `1.0.0-rc.1` 覆盖安装 `1.0.0-rc.2` 后，既有副标题、系列关系、季、
  篇序、公开结构标签、角色与范围保持不变。
- [ ] 未启用高级结构的系列，前台标题层、归档分组和阅读导航与升级前一致。

## 2. 简体中文术语

- [ ] WordPress 语言设为简体中文后，文章编辑器、系列编辑页、控制中心、系列健康、
  篇序与结构、归档及导航中的产品名称均统一显示“系列”。
- [ ] “篇序”“序文／前言”“顺序”“有序／无序”等原有准确术语没有被误改。
- [ ] Gutenberg 编辑器侧栏与 PHP 后台页面采用同一套“系列”译法。

## 3. 后台结构管理器

- [ ] “结构轨道”选择器仍分别显示全系列序文、每季序文／主要文章／尾声／附录、
  全系列尾声与全系列附录，便于准确移动条目。
- [ ] 本次前台简化没有合并后台轨道，也没有改变拖动、键盘移动、撤销或篇序。

## 4. 完整系列归档

准备一个至少两季且已启用高级结构的系列，并包含：全系列总序、第一季序文、主要
文章、尾声或附录、第二季主要文章、全系列后记。

- [ ] 给全系列总序填写公开结构标签“总序”，前台区块标题显示“系列总序”。
- [ ] 给全系列后记填写公开结构标签“后记”，前台区块标题显示“系列后记”。
- [ ] 上述条目不再显示“全系列序文／前言”“全系列尾声／后记”等内部角色标题。
- [ ] 公开结构标签已用于区块标题后，不会在同一文章行中重复显示一次。
- [ ] 暂时清空一个全系列非主要条目的公开结构标签，前台只显示“系列”，不会以
  “序文／前言”“尾声／后记”或“附录”替代。

## 5. 单季公开分组

- [ ] 完整归档中每一季只出现一个季标题。
- [ ] 季标题下依次显示该季序文、主要文章、尾声与附录，但不出现
  “季名 — 主要文章”等轨道标题。
- [ ] 某季没有序文、尾声或附录时，只显示季名及现有内容，不暗示缺少其他角色。
- [ ] 打开 `?wptl_season=数字` 的单季页面时，同样只出现一个季标题，且不混入
  全系列条目或其他季内容。
- [ ] 有序系列的主要文章篇号保持连续；无序系列仍按其归档排序设置排列主要文章。

## 6. 单篇标题层与响应式外观

- [ ] 非主要条目填写公开结构标签后，单篇题头显示该标签；清空后不泄露内部角色名。
- [ ] 桌面与手机上，全系列区块隐藏重复标签后，文章标题与特色图像仍占用正常宽度，
  不会挤进原本留给篇号的窄列。
- [ ] 系列、季与文章链接的原有颜色、hover、focus 和下划线行为没有变化。
